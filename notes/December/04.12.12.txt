Joins and Sub queries and Triggers

Subquery
    Sub query is a query inside another query it runs first, produce a value/table, and the outer query uses that result.
    To compare the value with the calculate result to filter rows based on another table 
    To replace joins in small cases 
    To find dynamic values 
    To check existence of related data  
    Helps as to make query smart and more flexible 

    You need a calculate values

Scalar Subquery:
    Returns one value 
    used in where and select condition 

    select * from tablename where salary > (select product_price from products)
    select * from tablename where salary = (select product_price from products)
    select * from tablename where salary < (select product_price from products)

Inner query 
    Returns single value 

Column Subquery
    Column Subquery Returns one column multiple rows 

    in, or, not in 

    select emp_depart from emp;
    select emp_name from emp where emp_depart in (select emp_depart from emp)

Row Subquery
    Returns one rows 

    select emp_depart, max(emp_salary) from emp;
    select * from emp where (emp,depart, emp_salary) = ()
