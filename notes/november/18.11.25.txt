Nullish coalescing:
The ?? operator: It checks the value on its left.  
If the left value is null or undefined: The operator returns the value on the right.  
If the left value is not null or undefined: The operator returns the left value, even if it's a falsy value like \(0\) or false. 


{off ?? <section>
    <div>
    <h3></h3>
    <p></p>
    </div>
 </section> <p> There is no content</p> }
 </section>:""}
