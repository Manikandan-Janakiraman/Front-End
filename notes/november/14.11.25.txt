React :
    React base itself = component based architecture.
    component = reusable ui and process, logic, and styling inside the single small unit of function
    called component.
    Components are reusable.
    When u make a component the component name must be first letter capital.
    Each component have their own logic and style.
    In your project wherever you can make a single component use it in many places
    header, footer, login form, cart products.
    Component are building blocks of your project or website.
    Component is a small piece of ui and logic.
    We can maintain dynamic component and static component.

Two types of component:
    function component - modern react standard
    class component - use it before 2020 (large codes, not syntactic, understand is difficult)


Real Dom:
    Raw Html File 
    browser directly update the ui 

react handle virtual DOM
    react creates a copy of dom memory
    light weight js object 
    react updates virtual dom compares with previous snapshoot (diffing algorithm) 
    applies only that to real dom (reconciliation) 

Why Virtal DOM is faster
    React update only the required path not the full page thatswhy lightning fast performance.
