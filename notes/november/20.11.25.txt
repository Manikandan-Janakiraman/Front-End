State :
-> State is a Built-in React Object hold the data or information about the component.
-> Memory of react 
-> component data storage 
-> data is updated over the time
-> the component is re- render to reflect those changes.
-> When state is changes the component re-render the component to store the data.

State Features 
-> State is a mutable
-> State triggers Re-render
-> State is a asynchronous process 
-> REact batches multiple state updates for performance
-> State update take time to process
-> Do not access Immediately
