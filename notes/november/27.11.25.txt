SQL Commands are grouped into 5 major types
    DDL -> Data Definition Language (database and table handle)
            used to define add, change or modify the data
            Create | Alter | Drop | Truncate | Rename | Change 

    DML -> Data Manipulation Language
            used to modify rows inside the table 
            Insert | Delete | update

    DQL -> Data Query Language
            used to fetch the datas (retrieve) from the database, using single line comment 

    Joins -> join the table (2 or more)
            inner join, left join, right join, full join

    Constraints -> using data accuracy and validity
            Primary Key, Foreign Key, Unique, Not Null, check, default 

    TCL -> Transaction Control Language
    DCL -> Data control Language
